## Caption rules (for every new reel)
1. **First line = hook** (Instagram shows only 1–2 lines before "more").
2. Use 3–6 value lines with emoji bullets, and only numbers from `SOURCES.md`.
3. Add an easy comment question (quiz: "A ya B").
4. Add a Like ❤️ Share ✈️ Repost 🔁 + follow @howtohindi.official line.
5. Add a **🔎 Keywords section** with 12–20 search phrases:
   - Hinglish: "kya hai", "kaise kare", "kaise kaam karta hai"
   - English: "explained in Hindi", "how … works"
   - Exact names: NPCI, Vikram lander, CIBIL…
   - Dates and numbers
   - 3–5 Hindi (Devanagari) phrases
6. Use 10–12 hashtags: 4–5 topic tags, 3–4 category tags (#FinanceInHindi, #ScienceInHindi…) and the 3 brand tags (#HowToHindi #HindiExplainer #ReelsIndia).
